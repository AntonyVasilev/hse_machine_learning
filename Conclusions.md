### Структура проекта:
- Корень проекта
    1. `.gitignore` - игнорируемые файлы и каталоги для git
    2. `AI_HW1_Vasilev_Anton.ipynb` - ipython ноутбук с выпоненным заданием
    3. `app.py` - основной скрипт с приложением на streamlit
    4. `functions.py` - функции, необходимые для работы приложения из `app.py`
    5. `cars_test.csv` - пример тестовых данных для предсказания стоимости автомобилей
- Папка `data` - файлы в форматах `json` и `pickle`. Дополнительные данные, необходимые для корретного функционирования приложения. Все сохраненные данные ввяты из `AI_HW1_Vasilev_Anton.ipynb`
- Папка `models` - файлы в формате `pickle`. Содержит обученную `Ridge` модель, а также обученные энкодеры и скалеры для подготовки загружаемых/вводимых данны и приведения их к виду, требуемому моделью.
  
### Проделанная работа:
1. Выполнил все пункты задания из `AI_HW1_Vasilev_Anton.ipynb`
    - Подготовил данные: заполнил пропуски медианными значениями, удалил дубли в данных, преобразовал признаки к корректным типам
    - Сделал фича-инжениринг - добавил полиноминальные фичи, а также бинарный признак с указание какие значения были изначально пустые и были заполнены медианными.
    - Обучил несколько линейных моделей: `LinearRegression`, `Lasso`, `Ridge`, `ElasticNet`
    - По каждому эксперименту сделал оценку качества паредсказания. Основная метрика - $R^2$, вспомогательная $MSE$
    - Реализовал 2 бизнес-метрики: доля прогнозов, отличающихся от факта не долее чем на 10%, и прибыль.
2. Реализовал приложение на `Streamlit`
    - Визуализировал веса обученной модели (добавил chekbox, позволяющий добавить intercept на график)
    - Реализовал выбор варианта получения прогноза и выполнение определенной логики для каждого из вариантов
    - Вариант с загрузкой csv-файла добавил форму выбора файла для загрузки. Далее выполняется визуализация данных - 4 графика, делается предсказание, рассчитываются метрики качества ($R^2$ и $MAPE$). Добавил кнопку для скаячивания результата предсказания в формате csv-файла
    - Вариант с вводом данных для предсказания через форму. Сделал генерацию формы для выбора (категориальные) и ввода (числовые) значений, на которых делаем предсказание. По нажатию пользователем на кнопку `Получить предсказание`, модель делает предсказание на данных из формы и результат выводится на экран
